2. Writing a number as a power of a chosen base

What you will be able to do

  • Find the exponent that turns a base into a given number.
  • Use a negative exponent for one over a power.
  • Set exponents equal when the bases match.

The goal

The first method in the lecture works when both sides of an equation can be written with the same base. For that you need to look at a number such as 81 and rewrite it as a power: 81 = 3^4. 81 equals 3 to the power 4 .

How to find the power

The equation tells you which base to use. It is the base already sitting on the other side. Raise that base to 2, then 3, then 4, until you hit the number.

3^2 = 9 3 squared equals 9 3^3 = 27 3 cubed equals 27 3^4 = 81 3 to the power 4 equals 81

You do not need to know these by heart. The instructor does this search in Desmos with the caret key and says so in the video.

Fractions use negative exponents

If the number is one over a power, the exponent is negative. 1/9 = 1/3^2 = 3^-2. 1 over 9 equals 1 over 3 squared equals 3 to the power negative 2 .

Same base, same exponent

Once both sides are powers of the same base, the exponents must be equal. This is the one-to-one property for exponents. So the bases drop away and you are left with an equation made of the exponents only.

3^x = 3^4 gives x = 4 3 to the power x equals 3 to the power 4 gives x equals 4 5^(x + 1) = 5^3 gives x + 1 = 3 5 to the power x plus 1, equals 5 cubed gives x plus 1 equals 3

This only works when the bases match. From 3^x = 5^2 3 to the power x equals 5 squared you cannot conclude x = 2 x equals 2 .

Why the exponents must match. The graph of y = 3^x y equals 3 to the power x always rises. It never comes back to a height it has already passed. So each output comes from exactly one exponent. If 3 to some power equals 3 to another power, they must be the same power. That is what one-to-one means: one input for each output.

Rewrite, then match

Rewrite 2^(x + 3) = 32 2 to the power x plus 3, equals 32 so both sides have base 2. Then write the equation the exponents give.

  1. 2^5 = 32 2 to the power 5 equals 32 Raise 2 to powers until you reach 32.
  2. 2^(x + 3) = 2^5 2 to the power x plus 3, equals 2 to the power 5 Replace 32 with 2^5. 2 to the power 5 .
  3. x + 3 = 5 x plus 3 equals 5 Same base, so the exponents are equal.

The exponents give x + 3 = 5 x plus 3 equals 5 .

3. Solving the equation that is left

What you will be able to do

  • Solve a linear equation, including x on both sides.
  • Set a quadratic equal to zero and factor.
  • Keep both answers of a quadratic.

What is left

After the bases or the logs are gone, an ordinary equation remains. It is one of two kinds. If x appears only to the first power, it is linear. If there is an x^2 x squared , it is quadratic.

Linear: undo in reverse order

Move the plain number first by adding or subtracting. Then divide by the number in front of x.

3x - 2 = 4 3 x minus 2 equals 4 3x = 6 3 x equals 6 x = 2 x equals 2

If x is on both sides, collect the x terms on one side first.

5x + 1 = 2x + 10 5 x plus 1 equals 2 x plus 10 3x + 1 = 10 3 x plus 1 equals 10 3x = 9 3 x equals 9 x = 3 x equals 3

Quadratic: set equal to zero, then factor

A quadratic is not solved by moving things around until x is alone. Instead, get everything on one side so the other side is 0. Then factor and set each factor equal to zero.

x^2 - x = 6 x squared minus x equals 6 x^2 - x - 6 = 0 x squared minus x minus 6 equals 0 (x - 3)(x + 2) = 0 open parenthesis x minus 3 close parenthesis open parenthesis x plus 2 close parenthesis equals 0 x = 3 or x = -2 x equals 3 or x equals negative 2

To factor x^2 - x - 6 x squared minus x minus 6 , find two numbers that multiply to -6 negative 6 and add to -1 negative 1 . They are -3 negative 3 and 2. A quadratic usually gives two answers. Keep both until you have checked them.

Desmos can find the answers too

The lecture allows Desmos for this step. Type the quadratic, with zero on one side removed, as y = x^2 - x - 6 y equals x squared minus x minus 6 . The graph crosses the x-axis at the solutions. Click the crossing points to read them.

Why a quadratic is set equal to zero. If two numbers multiply to zero, one of them has to be zero. That is the only way to get a product of 0. So once a quadratic is written as (x - 3)(x + 2) = 0 open parenthesis x minus 3 close parenthesis open parenthesis x plus 2 close parenthesis equals 0 , either x - 3 x minus 3 is zero or x + 2 x plus 2 is zero. This is why the other side must be 0 first. If the product equaled 6, you could not say anything about the separate factors.

A quadratic from start to finish

  1. x^2 - 2x - 15 = 0 x squared minus 2 x minus 15 equals 0 Subtract 15 from both sides so one side is 0.
  2. (x - 5)(x + 3) = 0 open parenthesis x minus 5 close parenthesis open parenthesis x plus 3 close parenthesis equals 0 -5 negative 5 and 3 multiply to -15 negative 15 and add to -2 negative 2 .
  3. x = 5 or x = -3 x equals 5 or x equals negative 3 Set each factor equal to zero.

Answer: x = 5 x equals 5 and x = -3 x equals negative 3

4. A logarithm of a number is just a number

What you will be able to do

  • Divide both sides by a logarithm of a number.
  • Keep an exact answer exact, and round the decimal one.
  • Isolate the exponential before taking a log.

The idea

ln(20) the natural log of 20 looks like something to be worked out, but it is simply a number, about 2.996. ln(3) the natural log of 3 is about 1.099. In the second method of the lecture, numbers like these end up multiplied by x. You treat them exactly as you would treat a 5 or a 20.

5x = 20 divide by 5 x = 20/5 5 x equals 20 divide by 5 x equals 20 over 5 x * ln(3) = ln(20) divide by ln(3) x = ln(20)/ln(3) x times the natural log of 3 equals the natural log of 20 divide by the natural log of 3 x equals the natural log of 20 over the natural log of 3

Exact answer and decimal answer

ln(20)/ln(3) the natural log of 20 over the natural log of 3 is the exact answer. MyMathLab often asks for it first. Leave it exactly like that. The decimal approximation comes from typing it into Desmos and rounding: about 2.73.

What you cannot do

ln(20)/ln(3) the natural log of 20 over the natural log of 3 is two separate logs divided. It is not ln(20/3) the natural log of 20 over 3, end log, , and the "ln" does not cancel to leave 20/3. Check with Desmos: ln(20)/ln(3) the natural log of 20 over the natural log of 3 is about 2.73, while ln(20/3) the natural log of 20 over 3, end log, is about 1.90.

More than x on the left

If the exponent was x + 5 x plus 5 , then after the log step the equation is (x + 5) open parenthesis x plus 5 close parenthesis * ln(2) = ln(40) the natural log of 2 equals the natural log of 40 . Divide by ln(2) the natural log of 2 first. Then subtract 5.

(x + 5) * ln(2) = ln(40) open parenthesis x plus 5 close parenthesis times the natural log of 2 equals the natural log of 40 x + 5 = ln(40)/ln(2) x plus 5 equals the natural log of 40 over the natural log of 2 x = ln(40)/ln(2) - 5 x equals the natural log of 40 over the natural log of 2 minus 5

The - 5 sits after the fraction, not in its bottom. In Desmos, press the right arrow to leave the fraction before typing - 5.

Isolate first

If a number multiplies the exponential, divide it away before taking any log. From 3e^x = 12 3 e to the power x equals 12 , divide both sides by 3 to get e^x = 4 e to the power x equals 4 . Then the natural log finishes it, because ln(e^x) the natural log of e to the power x, end log, is just x.

Why you can divide by ln(3) the natural log of 3 . Solving 5x = 20 5 x equals 20 works because dividing both sides by 5 keeps the equation balanced. Nothing about that depends on 5 being a whole number. It works for 5, for 1.099, and for ln(3) the natural log of 3 , since ln(3) the natural log of 3 is 1.099 written exactly. The instructor says it this way: it is "just a number that's yet to be computed."

Divide, then subtract

5. Distributing and clearing a fraction

What you will be able to do

  • Distribute a number or an x.
  • Use the powers 0 and 1.
  • Multiply both sides by a denominator.

Distributing

A factor in front of parentheses multiplies every term inside.

5(x + 2) = 5x + 10 5 open parenthesis x plus 2 close parenthesis equals 5 x plus 10 x(2x + 5) = 2x^2 + 5x x open parenthesis 2 x plus 5 close parenthesis equals 2 x squared plus 5 x

In the second line, x times 2x is 2x^2 2 x squared , because x * x = x^2. x times x equals x to the power 2 . This is how a logarithmic equation can turn into a quadratic.

Two small powers that show up

When a logarithmic equation is converted to exponential form, the power is often very small.

  • Any base to the power 0 is 1. So 6^0 = 1 6 to the power 0 equals 1 .
  • Any base to the power 1 is itself. So 9^1 = 9 9 to the power 1 equals 9 .

Clearing a fraction

If x is in the bottom of a fraction, multiply both sides of the equation by the whole bottom. On the fraction's side the bottom cancels. On the other side it multiplies, and you distribute.

2 = (x + 8)/(x - 3) 2 equals open parenthesis x plus 8 close parenthesis over open parenthesis x minus 3 close parenthesis 2(x - 3) = x + 8 2 open parenthesis x minus 3 close parenthesis equals x plus 8 2x - 6 = x + 8 2 x minus 6 equals x plus 8 x = 14 x equals 14

Treat the bottom as one block. The 2 multiplies all of x - 3 x minus 3 , so parentheses are needed.

Why multiplying by the bottom clears the fraction. Dividing by something and then multiplying by the same thing gets you back where you started. So multiplying (x + 8 x plus 8 )/(x - 3 x minus 3 ) by (x - 3) open parenthesis x minus 3 close parenthesis leaves x + 8 x plus 8 . To keep the equation balanced, the other side has to be multiplied by (x - 3) open parenthesis x minus 3 close parenthesis too. Check the answer in the original: (14 + 8 14 plus 8 )/(14 - 3 14 minus 3 ) = 22/11 = 2 22 over 11 equals 2 . It works.

6. Checking an answer against the domain

What you will be able to do

  • State what a logarithm can take in.
  • Test a value in each argument of the original equation.
  • Recognize when there is no solution.

What a logarithm can take in

A logarithm asks "the base to what power gives this number?" A positive base raised to any power gives a positive result. So the number inside a logarithm, called its argument, must be positive. You cannot take the log of 0 or of a negative number. The set of allowed inputs is the domain.

Why algebra can hand you a bad answer

The steps for solving a logarithmic equation remove the logs. Once they are gone, the algebra no longer knows about the positive-only rule. So it can produce a value of x that makes an argument zero or negative. That value has to be thrown out. The directions say "reject any value of x that is not in the domain."

How to check

  1. Go back to the original equation, before any steps.
  2. Put the value of x into each argument, the expression inside each log.
  3. If every argument comes out positive, keep the value. If any argument is 0 or negative, reject it.

It is the argument that matters, not x

A negative x is not automatically rejected. For log_2(x + 6) log base 2 of x plus 6, end log, with x = -2 x equals negative 2 , the argument is -2 + 6 = 4 negative 2 plus 6 equals 4 , which is positive. So x = -2 x equals negative 2 is fine. And a positive x is not automatically safe. For log(2x - 9) log of 2 x minus 9, end log, with x = 3 x equals 3 , the argument is 6 - 9 = -3 6 minus 9 equals negative 3 . So x = 3 x equals 3 is rejected.

When nothing survives

If every value is rejected, the equation has no solution. That is a real answer, and MyMathLab has a choice for it.

With Desmos

The lecture also checks by typing the original equation's side into Desmos with the value in place of x. If Desmos shows "undefined," the value is not in the domain.

Why the argument must be positive. Try to find log(-100) log of negative 100, end log, . It asks "10 to what power gives -100 negative 100 ?" Positive powers give 10, 100, 1000. Zero gives 1. Negative powers give 1/10, 1/100. Every result is positive. No power of 10 will ever land on -100 negative 100 or on 0. There is no answer to the question, so the logarithm does not exist there.

Keep or reject

An equation contains log(x) log of x and log(x - 3) log of x minus 3, end log, . Solving gave x = 5 x equals 5 and x = -2 x equals negative 2 . Which values are kept?

  1. x = 5: arguments are 5 and 2 x equals 5 : arguments are 5 and 2 Both are positive. Keep 5.
  2. x = -2: the first argument is -2 x equals negative 2 : the first argument is negative 2 Negative. Reject -2 negative 2 without checking further.

Only x = 5 x equals 5 is a solution.
