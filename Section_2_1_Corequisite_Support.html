2. Ordered pairs, inputs, and outputs

What you will be able to do

  • Name the input and output of an ordered pair.
  • List inputs and outputs without repeats.
  • Spot an input that appears twice.

What an ordered pair says

An ordered pair is two numbers in parentheses, like (3, 8). The order matters. The first number is the x-value. The second number is the y-value. In this chapter the first number is also called the input and the second number is called the output. You can read (3, 8) as "when 3 goes in, 8 comes out."

A set is a collection of things written inside braces { }. The lecture writes a group of ordered pairs as a set, such as {(3, 8), (4, 1), (6, 8)}. A set of ordered pairs is called a relation. That word only means "some inputs paired with some outputs."

Listing the inputs and the outputs

Two jobs come up over and over in Section 2.1. The first is to list every input. The second is to list every output. To list the inputs, walk through the pairs and write down each first number. To list the outputs, write down each second number. Two habits make the lists correct:

  • Write each number only once, even if it shows up in several pairs. A set does not repeat a value.
  • Write the numbers in order from smallest to largest. This is not required, but it makes your list easy to check.
A picture that helps. Think of a vending machine. The buttons are the inputs. The snacks are the outputs. If you were asked "which buttons does this machine have," you would name each button once. You would not name a button twice because two people pressed it. Listing inputs and outputs works the same way.

Does an input repeat?

The lecture will ask whether any input is paired with two different outputs. The skill underneath is simply spotting a repeated first number. In {(2, 6), (5, 3), (2, 0)} the input 2 appears twice. It goes to 6 in one pair and to 0 in another. In {(2, 6), (5, 6)} no input repeats. The output 6 repeats, but that is a different thing. Always ask the question about the first numbers.

3. Substituting numbers: negatives and powers

What you will be able to do

  • Substitute with parentheses every time.
  • Tell (-3)^2 open parenthesis negative 3 close parenthesis squared from -3^2. negative 3 to the power 2 .
  • Predict the sign of a negative number raised to a power.
  • Evaluate a formula that contains a square root.

What substituting means

To substitute is to replace a letter with a number. To evaluate is to substitute and then do the arithmetic. The safest habit in all of algebra is this: when you replace a letter, put the number in parentheses. Every time. It costs one second and it prevents the most common errors on this page.

3x + 4 with x = 5 becomes 3(5) + 4 = 15 + 4 = 19 3 x plus 4 with x equals 5 becomes 3 open parenthesis 5 close parenthesis plus 4 equals 15 plus 4 equals 19

Function notation is a name, not multiplication

The lecture writes rules like f(x) = 3x + 4 f open parenthesis x close parenthesis equals 3 x plus 4 . Read f(x) as "f of x." The letter f is the name of the rule. The x in parentheses is the input. So f(x) does not mean f times x. Writing f(5) means "use 5 as the input." You replace every x in the rule with (5). Other letters work the same way. A rule can be named g or h, and the input letter can be r or t.

f(x) = 3x + 4 f open parenthesis x close parenthesis equals 3 x plus 4 f(5) = 3(5) + 4 = 19 f open parenthesis 5 close parenthesis equals 3 open parenthesis 5 close parenthesis plus 4 equals 19

Negatives with powers

Order of operations says powers come before negative signs and before multiplication. That is why parentheses matter so much with negative inputs.

(-3)^2 = (-3)(-3) = 9 open parenthesis negative 3 close parenthesis squared equals open parenthesis negative 3 close parenthesis open parenthesis negative 3 close parenthesis equals 9 -3^2 = -(3 * 3) = -9 negative 3 squared equals negative open parenthesis 3 times 3 close parenthesis equals negative 9

In the first line the parentheses make -3 negative 3 the thing being squared. In the second line only the 3 is squared and the negative sign waits outside. When you substitute -3 negative 3 for x in x^2 x squared , you mean the first line. The parentheses habit gives you the right one automatically.

A pattern worth knowing. A negative times a negative is positive. So an even number of negative factors gives a positive answer, and an odd number gives a negative answer. (-2)^2 = 4 open parenthesis negative 2 close parenthesis squared equals 4 and (-2)^4 = 16 open parenthesis negative 2 close parenthesis to the power 4 equals 16 are positive. (-2)^3 = -8 open parenthesis negative 2 close parenthesis cubed equals negative 8 and (-2)^5 = -32 open parenthesis negative 2 close parenthesis to the power 5 equals negative 32 are negative. You can predict the sign before you do any arithmetic.

4. Substituting an expression

What you will be able to do

  • Substitute an expression using parentheses.
  • Raise a product like 3a to a power.
  • Simplify even and odd powers of -x negative x .

The input does not have to be a number

The lecture will put things like -x negative x , 3a, or x - 4 x minus 4 into a function. This looks strange at first, but nothing new is happening. You still replace every x with the input in parentheses. The only difference is that you simplify with algebra, not arithmetic. The answer will be an expression, not a single number.

f(x) = 2x + 3 f open parenthesis x close parenthesis equals 2 x plus 3 f(a) = 2(a) + 3 = 2a + 3 f open parenthesis a close parenthesis equals 2 open parenthesis a close parenthesis plus 3 equals 2 a plus 3 f(x + 4) = 2(x + 4) + 3 = 2x + 8 + 3 = 2x + 11 f open parenthesis x plus 4 close parenthesis equals 2 open parenthesis x plus 4 close parenthesis plus 3 equals 2 x plus 8 plus 3 equals 2 x plus 11

In the last line the 2 was distributed: it multiplied both the x and the 4. Then the like terms 8 and 3 were combined.

A power of a product

When a product is raised to a power, every factor gets the power. This matters when the input is something like 2a.

(2a)^2 = (2a)(2a) = 2 * 2 * a * a = 4a^2 open parenthesis 2 a close parenthesis squared equals open parenthesis 2 a close parenthesis open parenthesis 2 a close parenthesis equals 2 times 2 times a times a equals 4 a squared (2a)^3 = 2 * 2 * 2 * a * a * a = 8a^3 open parenthesis 2 a close parenthesis cubed equals 2 times 2 times 2 times a times a times a equals 8 a cubed

The most common slip is to raise only the letter and leave the number alone, writing 2a^2 2 a squared when the answer is 4a^2. 4 a to the power 2 . Writing the product out, as above, shows why the number gets the power too.

Powers of -x negative x

Think of -x negative x as (-1)(x) open parenthesis negative 1 close parenthesis open parenthesis x close parenthesis . Then the rule above applies.

(-x)^2 = (-x)(-x) = x^2 open parenthesis negative x close parenthesis squared equals open parenthesis negative x close parenthesis open parenthesis negative x close parenthesis equals x squared (-x)^3 = (-x)(-x)(-x) = -x^3 open parenthesis negative x close parenthesis cubed equals open parenthesis negative x close parenthesis open parenthesis negative x close parenthesis open parenthesis negative x close parenthesis equals negative x cubed (-x)^4 = x^4 open parenthesis negative x close parenthesis to the power 4 equals x to the power 4
Why the sign behaves this way. It is the same sign pattern as with numbers. An even number of negative factors gives a positive. An odd number gives a negative. So an even power "erases" the negative sign and an odd power keeps it. Test it with x = 2 x equals 2 : (-2)^2 = 4 open parenthesis negative 2 close parenthesis squared equals 4 and 2^2 = 4 2 squared equals 4 , the same. (-2)^3 = -8 open parenthesis negative 2 close parenthesis cubed equals negative 8 and 2^3 = 8 2 cubed equals 8 , opposites.

5. Solving for y, and when two answers appear

What you will be able to do

  • Solve a simple equation for y.
  • Use the square root property to undo y^2. y to the power 2 .
  • Explain why y^2 = 25 y squared equals 25 has two answers and sqrt(25) the square root of 25 has one.

What "solve for y" means

To solve for y is to rearrange an equation so that y is alone on one side. You do it with the same balance moves used in Chapter 1. Whatever you do to one side, you do to the other. The answer is not a number this time. It is a formula that tells you y for any x.

x + y = 7 x plus y equals 7 y = 7 - x (subtract x from both sides) y equals 7 minus x open parenthesis subtract x from both sides close parenthesis

Why does the lecture do this? Once y is alone, you can see what happens to an input. You put in an x and the formula hands back y. The question the lecture asks is whether it hands back one y or more than one.

When y is squared

If the equation has y^2 y squared , getting y alone takes one more move: a square root on both sides. Chapter 1 called this the square root property. It always produces two answers, one positive and one negative, written with the plus-or-minus symbol.

y^2 = 25 y squared equals 25 y = +-5, which means y = 5 or y = -5 y equals plus or minus 5, which means y equals 5 or y equals negative 5
Why there are two. Both 5 * 5 5 times 5 and (-5)(-5) open parenthesis negative 5 close parenthesis open parenthesis negative 5 close parenthesis equal 25. So two different numbers have the same square. When you undo a square you have to report both. This is the whole reason a y^2 y squared in an equation is a warning sign in Section 2.1: one input can lead to two outputs.

The square root symbol gives one answer

This part confuses many people, and for good reason. The symbol sqrt( ) the square root of, end root, by itself means only the answer that is not negative. sqrt(25) the square root of 25 is 5. It is not -5 negative 5 . The plus-or-minus appears only when you take a square root to undo a square. So:

  • y^2 = 25 y squared equals 25 gives two values of y: 5 and -5 negative 5 .
  • y = sqrt(25) y equals the square root of 25 gives one value of y: 5.

  2. y^2 = 9 y squared equals 9 Add.
  3. y = +-3 y equals plus or minus 3 Square root property. Both 3 and -3 negative 3 square to 9.

Answer: y = 3 y equals 3 or y = -3 y equals negative 3 . One input gave two outputs.

6. Tables of values and reading a graph

What you will be able to do

  • Build a table of values.
  • Read an output and the intercepts from a graph.
  • Describe how far a graph reaches with interval notation.
  • Count how many times a vertical line crosses a graph.

A table of values

A table of values is a list of inputs with the output for each one. To build it, pick an x, substitute, and write down the y. Each row is an ordered pair (x, y). Plot the pairs as points and connect them, and you have a graph. The lecture lets Desmos build the table, but it expects you to know where the numbers come from.

For a square root rule, choose inputs that make the inside a perfect square, such as 0, 1, 4, 9, and 16. Then the outputs are whole numbers and easy to plot.

Reading a point from a graph

A graph is a picture of every pair in the table. To find the output for an input, start at that x on the horizontal axis, move straight up or down until you hit the curve, then read the height on the vertical axis. That height is y.

On Graph A, start at x = 1 x equals 1 and move down to the curve. You land at height -3 negative 3 . So when the input is 1 the output is -3 negative 3 . In function notation, f(1) = -3 f open parenthesis 1 close parenthesis equals negative 3 .

Intercepts

An x-intercept is a point where the graph touches or crosses the x-axis. The y-value there is 0. A y-intercept is where the graph crosses the y-axis. The x-value there is 0. Graph A has two x-intercepts, at x = -2 x equals negative 2 and x = 2 x equals 2 , and one y-intercept, at y = -4 y equals negative 4 .

How far the graph reaches

The lecture asks for the domain (all the x-values the graph uses) and the range (all the y-values it uses). The skill underneath is describing how far a graph reaches. For x, read from the far left to the far right. For y, read from the lowest point to the highest point. Write the result in interval notation from Section 1.7: a bracket [ ] means the end value is included, and a parenthesis ( ) means it is not. On a graph, a filled dot means included and an open dot means not included.

A picture that helps. Imagine a light shining straight down from above Graph B. The shadow on the x-axis runs from -5 negative 5 to 3. That shadow is the set of x-values used. The filled dot at -5 negative 5 means -5 negative 5 is used. The open dot at 3 means 3 is not. So the x-values are [-5 negative 5 , 3). Now shine a light from the side. The shadow on the y-axis runs from -3 negative 3 up to 1. Always write the smaller number first: (-3 negative 3 , 1]. The -3 negative 3 gets a parenthesis because it belongs to the open dot.

Counting crossings of a vertical line

A vertical line is all the points that share one x-value. If you draw a vertical line at x = 0 x equals 0 , every place it crosses the graph is an output for the input 0. So counting crossings is the same as counting outputs for that input. The lecture builds a test out of this idea.

On Graph C the dashed line at x = 0 x equals 0 crosses the curve at (0, 2) and at (0, -2) open parenthesis 0, negative 2 close parenthesis . The input 0 has two outputs.
