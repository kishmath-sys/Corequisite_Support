2. Reading the four inequality symbols

What you will be able to do

  • Read each symbol in words.
  • Decide if a comparison of two numbers is true.
  • Match the symbol to a solid or dashed boundary.

The symbols

An inequality compares two amounts that do not have to be equal. The open end of the symbol faces the larger amount. The small pointed end faces the smaller amount.

The four inequality symbols
SymbolRead it asBoundary is part of the answer?Line style
<is less thanNoDashed
>is greater thanNoDashed
≤is less than or equal toYesSolid
≥is greater than or equal toYesSolid

What "or equal to" changes

The statement 5 ≥ 5 5 is greater than or equal to 5 is true, because 5 is equal to 5 and "or equal to" allows that. The statement 5 > 5 5 is greater than 5 is false, because 5 is not greater than itself. That one difference is the whole reason some boundary lines are solid and some are dashed.

On a graph, the boundary is the line where the two sides are exactly equal. With ≤ or ≥, points on the boundary count, so the line is drawn solid. With < or >, points on the boundary do not count, so the line is drawn dashed. A dashed line says "the region goes right up to here, but this edge is not included."

Negative numbers

On a number line, smaller numbers are to the left. So -3 negative 3 is less than -1 negative 1 , even though 3 is more than 1.

Typing them in Desmos

The keyboard has < and >. For ≤ type the less than sign and then the equals sign. For ≥ type the greater than sign and then the equals sign. Desmos joins them into one symbol and draws the solid or dashed line for you.

Why the edge needs its own decision. Think of a speed limit. "You must drive less than 55" means 55 itself is not allowed. "You may drive 55 or less" means 55 is fine. Same number, but one rule includes the edge and the other does not. Solid and dashed lines are the graph's way of saying which kind of rule it is.

3. Two points make a boundary line

What you will be able to do

  • Write the boundary equation.
  • Find points by setting x = 0 x equals 0 and y = 0 y equals 0 .
  • Find points by choosing x-values.

Pretend it is an equals sign

To draw the boundary, replace the inequality symbol with an equals sign for a moment. The boundary of 3x + 4y ≤ 12 3 x plus 4 y is less than or equal to 12 is the line 3x + 4y = 12 3 x plus 4 y equals 12 . The MyMathLab line tool needs two points on that line. Any two will do, so choose easy ones.

When x and y are on the same side: use zeros

Set x = 0 x equals 0 and solve for y. Then set y = 0 y equals 0 and solve for x. A term with a zero in it disappears, so each one is a one-step equation.

3x + 4y = 12 3 x plus 4 y equals 12 x = 0: 4y = 12, y = 3 point (0, 3) x equals 0 : 4 y equals 12, y equals 3 point open parenthesis 0, 3 close parenthesis y = 0: 3x = 12, x = 4 point (4, 0) y equals 0 : 3 x equals 12, x equals 4 point open parenthesis 4, 0 close parenthesis

Keep the order straight when you write the point. The x-value goes first even when you found y first.

When y is alone: pick x-values

If the line is written as y = 3x - 5 y equals 3 x minus 5 , choose any x and compute y. Zero is the easiest choice. Then choose one more.

y = 3x - 5 y equals 3 x minus 5 x = 0: y = 3(0) - 5 = -5 point (0, -5) x equals 0 : y equals 3 open parenthesis 0 close parenthesis minus 5 equals negative 5 point open parenthesis 0, negative 5 close parenthesis x = 2: y = 3(2) - 5 = 1 point (2, 1) x equals 2 : y equals 3 open parenthesis 2 close parenthesis minus 5 equals 1 point open parenthesis 2, 1 close parenthesis
Why any two points work. Two points are enough because a straight line has no bends. Once it passes through two places there is only one way for it to go. And any point you compute from the equation is on the line, because being on the line means making the equation true. That is why you are free to pick whichever x-values make the arithmetic easy.

4. Testing a point to choose a side

What you will be able to do

  • Substitute a test point into an inequality.
  • Decide true or false.
  • Choose the side to shade.

A line splits the plane in two

A boundary line cuts the plane into two sides. Here is the fact that makes these problems manageable: on one side, every point makes the inequality true. On the other side, every point makes it false. So you only need to test one point.

The test

  1. Pick a point that is not on the boundary. The origin (0, 0) is the easiest when the line does not pass through it.
  2. Put its x and y into the original inequality.
  3. If the statement is true, shade the side that contains your test point. If it is false, shade the other side.
x + y ≤ 3 test (0, 0) x plus y is less than or equal to 3 test open parenthesis 0, 0 close parenthesis 0 + 0 ≤ 3 0 plus 0 is less than or equal to 3 0 ≤ 3 true 0 is less than or equal to 3 true

True, so the side containing (0, 0) is shaded. Graph C shows the result.

When the origin is on the line

A line such as y = 2x y equals 2 x passes through (0, 0), so the origin cannot be the test point. Pick any other easy point, such as (1, 0).

Use the original inequality

Test in the inequality as it was given, with its real symbol. The equals sign was only borrowed to draw the boundary.

Why one test point is enough. Walk across the plane from a point where the left side is smaller than the right side to a point where it is larger. Somewhere along the way the two sides have to be equal, and equal means you are standing on the boundary. So the only way to switch from true to false is to cross the line. Everything on one side of the line therefore gets the same answer.

A test that comes out false

5. Parabolas as boundaries

What you will be able to do

  • Find the vertex of y = x^2 + k y equals x squared plus k .
  • Tell if a parabola opens upward or downward.
  • Compute one more point and test the origin.

A boundary can curve

Some inequalities in this section have an x^2 x squared in them. The boundary is then a parabola, the U-shaped curve from Chapter 3. Everything else stays the same: solid or dashed, test a point, shade a side. The two sides are now "inside the U" and "outside the U".

What the MyMathLab parabola tool needs

It asks for the vertex and one more point. The vertex is the turning point of the U.

The vertex of y = x^2 + k y equals x squared plus k

For a parabola written as y = x^2 y equals x squared plus or minus a number, the vertex is on the y-axis at that number. The curve y = x^2 + 1 y equals x squared plus 1 has vertex (0, 1). The curve y = x^2 - 1 y equals x squared minus 1 has vertex (0, -1) open parenthesis 0, negative 1 close parenthesis . The reason: x^2 x squared is smallest when x = 0 x equals 0 , and then y is just the number.

Up or down

If the x^2 x squared term is positive, the parabola opens upward and the vertex is the lowest point. If there is a negative sign in front of x^2 x squared , it opens downward and the vertex is the highest point. y = -x^2 + 5 y equals negative x squared plus 5 opens downward from (0, 5).

One more point

Choose an x other than 0 and compute y. Square first, then apply any negative sign in front, then add or subtract.

y = x^2 - 1 at x = 2 y equals x squared minus 1 at x equals 2 y = (2)^2 - 1 y equals open parenthesis 2 close parenthesis squared minus 1 y = 4 - 1 = 3 point (2, 3) y equals 4 minus 1 equals 3 point open parenthesis 2, 3 close parenthesis y = -x^2 + 5 at x = 2 y equals negative x squared plus 5 at x equals 2 y = -(2)^2 + 5 y equals negative open parenthesis 2 close parenthesis squared plus 5 y = -4 + 5 = 1 point (2, 1) y equals negative 4 plus 5 equals 1 point open parenthesis 2, 1 close parenthesis
Why the vertex is at x = 0 x equals 0 . A square is never negative. (-3)^2 open parenthesis negative 3 close parenthesis squared and (3)^2 open parenthesis 3 close parenthesis squared are both 9. So x^2 x squared is at least 0, and it equals 0 only when x is 0. That makes x = 0 x equals 0 the place where y = x^2 + k y equals x squared plus k is as small as it can be, which is the bottom of the U. Putting a negative sign in front flips every height, so the bottom becomes the top.

6. Where two shadings overlap

What you will be able to do

  • Test a point in two inequalities.
  • Decide if it is in the overlap.
  • Shade only the overlap for the final answer.

A system means both at once

A system of inequalities lists two inequalities. A point is a solution only if it makes the first one true and the second one true. On a graph, the first inequality has its shaded region and the second has its own. The solution of the system is the part of the plane where the two regions lie on top of each other.

Checking a point against both

Put the point into each inequality separately.

(0, 1) in y ≥ x - 1: 1 ≥ -1 true open parenthesis 0, 1 close parenthesis in y is greater than or equal to x minus 1 : 1 is greater than or equal to negative 1 true (0, 1) in y < -x + 3: 1 < 3 true open parenthesis 0, 1 close parenthesis in y is less than negative x plus 3 : 1 is less than 3 true

Both true, so (0, 1) is in the overlap. If either one is false, the point is not a solution of the system, no matter how the other one comes out.

What to shade for the final answer

On paper it helps to shade each region lightly and look for where they cross. But the final answer is only the overlap. In MyMathLab you click the shading tool once, in the overlap region. Shading everything that either inequality covers is the most common mistake on these problems.

Desmos shows the overlap

Type each inequality on its own line. Desmos shades each one in a different color, and the overlap shows as the darker, blended area. You can use that picture to see which region to click in MyMathLab.

Why only the overlap counts. The word "and" is strict. "It is Saturday and it is raining" is false on a sunny Saturday. One true part does not rescue it. A system of inequalities is an "and" statement about a point, so the point has to pass both tests. The overlap is simply the set of points that pass both.

  2. 5 < -0 + 3 5 is less than negative 0 plus 3 Second inequality. 5 < 3 5 is less than 3 is false.
